# BugPilot

AI-powered Engineering Intelligence Platform for Bug Triage, Pull Request Review, and Repository Analytics.

## Vision

BugPilot AI helps developers analyze software issues using Artificial Intelligence by combining GitHub Issues, Pull Requests, Commits, and intelligent insights into one platform.

##  Planned Features

-  JWT Authentication
-  GitHub Repository Import
-  Issue Management
-  Pull Request Analysis
-  Commit Intelligence
-  AI Bug Analysis
-  Analytics Dashboard
-  Activity Timeline

##  Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- PostgreSQL

### Frontend

- TypeScript
- Material UI
